# 🍎 사과 송장 만들기

사과 주문을 입력하고 **확인**을 누르면 송장이 **PDF 파일로 저장**되고 바로 **인쇄**할 수 있는 프로그램입니다.
설치할 것 없이 `apple_invoice.html` 파일 하나만 있으면 됩니다.

## 시작하기

1. `apple_invoice.html` 파일을 **더블클릭** → 크롬이나 엣지 브라우저에서 열립니다.
2. 처음 한 번만 **📦 보내는 분 · 인쇄 설정**에 농장 이름과 전화번호를 입력합니다. (다음부터는 기억합니다)

## 🤖 주문 자동 인식 (가장 쉬운 방법)

맨 위 **주문 자동 인식** 칸에 주문을 넣기만 하면 **이름 · 전화번호 · 사과 종류 · 개수 · 주소 · 우편번호**를 알아서 찾아 채워줍니다.

| 이렇게 넣으세요 | 방법 |
|---|---|
| 📋 문자·카톡 글자 | 복사해서 칸에 **붙여넣기(Ctrl+V)** → 바로 인식 |
| 🖼️ 카톡·문자 캡처 | 캡처한 뒤 화면에서 **Ctrl+V** → 바로 인식 |
| 📷 주문서 사진 | 사진 파일을 칸으로 **끌어다 놓기**, 또는 **📷 사진·캡처 불러오기** 버튼 (휴대폰은 바로 촬영 가능) |

1. 인식이 끝나면 칸마다 ✅(찾음) / ⚠️(못 찾음)이 표시됩니다. ⚠️ 칸만 직접 채우면 됩니다.
2. 주소를 찾으면 **우편번호 검색이 자동으로 열려요.** 맞는 주소를 한 번 누르면 우편번호가 채워집니다.
3. 맞는지 보고 **✅ 확인**을 누르면 송장 PDF가 저장되고 인쇄할 수 있습니다.

> 사진 인식은 인쇄된 글자·캡처 화면에 잘 맞습니다. 손글씨는 잘 못 읽을 수 있으니 꼭 확인해 주세요.
> 처음 한 번은 인터넷에서 한글 글자 데이터(약 4MB)를 받아서 몇 초 더 걸립니다.

## 직접 입력하기

| 순서 | 할 일 |
|---|---|
| ① | **받는 분 이름**, **전화번호** 입력 |
| ② | **사과 종류** 고르기 (부사, 홍로, 감홍 … 없으면 *기타*에 직접 입력) |
| ③ | **개수** 입력 (박스 / 개 선택) |
| ④ | **주소** 입력 (동·호수는 아래 칸에) |
| ⑤ | **✅ 확인** 누르기 → 우편번호가 비어 있으면 자동으로 찾아줍니다 |

- 확인을 누르면 송장 PDF 파일이 **다운로드 폴더**에 저장되고(예: `송장_AP261031-001_홍길동.pdf`), 미리보기 창에서 **🖨️ 인쇄하기**를 누르면 바로 인쇄됩니다.
- 박스가 여러 개면 박스마다 송장이 1장씩 만들어집니다 (1/3, 2/3, 3/3).

## 편한 기능

- **📋 주문 목록**: 지난 주문을 다시 보기, 고치기(같은 송장번호 유지), 삭제할 수 있습니다.
  여러 건을 체크해서 한꺼번에 **PDF 저장 / 인쇄 / 엑셀 저장**도 됩니다.
- **인쇄 용지**: A4 용지(한 장에 송장 2개) 또는 라벨 프린터(100×150mm) 중에 고를 수 있습니다.

## 알아두세요

- 주문 기록은 **이 컴퓨터의 브라우저**에 저장됩니다. 브라우저 기록을 지우면 사라질 수 있으니 가끔 **📊 엑셀 저장**으로 백업해 두세요.
- 우편번호 찾기와 사진 인식은 **인터넷 연결**이 필요합니다. (인터넷이 없으면 직접 입력하거나 문자 글자를 붙여넣으면 됩니다)
- 송장번호(예: `AP261031-001`)는 농장에서 관리하는 번호입니다. 택배사에 한꺼번에 접수할 때는 **엑셀 저장** 파일을 활용하세요.
