# 🎯 발로란트 조준선 오버레이

**화면 정중앙에 조준선을 띄워 주는** 프로그램이에요. 조준선은 3가지 방법으로 정할 수 있어요.

- 📋 발로란트 **조준선 코드 붙여넣기**
- ⚙ 버튼/슬라이더로 **직접 만들기** (만든 조준선을 발로란트 코드로 복사 가능)
- ✏ 칸을 칠해서 **직접 그리기** (그린 그림도 발로란트 코드로 바꾸기 가능)

- 게임보다 **항상 위에** 떠요
- 마우스 클릭은 조준선을 **그대로 통과**해서 게임에 전달돼요
- **F8** 키로 켜기/끄기
- 마지막에 쓴 조준선, 그린 그림, 크기를 기억해요

## 실행 방법

**방법 1. exe 파일 (설치 필요 없음)**
1. GitHub 저장소 → **Actions** 탭 → `Valorant crosshair overlay` → 최신 실행 클릭
2. 아래 **Artifacts** 의 `ValorantCrosshair` 다운로드 → 압축 풀기
3. `ValorantCrosshair.exe` 더블클릭

**방법 2. 파이썬으로 실행**
1. [python.org](https://www.python.org) 에서 파이썬 설치
2. `조준선_실행.bat` 더블클릭

## 사용 방법

### ⚙ 만들기 탭
- **코드로 불러오기:** 발로란트 **설정 → 조준선 탭 → 프로필 옆 내보내기(Export) 버튼**으로 코드를 복사한 뒤 **📋 복사한 코드 붙여넣기**를 눌러요.
- **직접 만들기:** 색상 버튼과 슬라이더(테두리, 중앙 점, 안쪽 선, 바깥 선)를 움직이면 바로 바뀌어요.
- **게임에도 똑같이:** **📄 코드 복사**를 누르고 발로란트 조준선 설정의 **가져오기(Import)**에 붙여넣으면 게임 조준선도 똑같아져요.

### ✏ 그리기 탭
- **도구** (그림판처럼)
  - **▦ 픽셀:** 칸을 하나씩 칠해요.
  - **🖌 붓:** 부드럽게 자유롭게 그려요. 가장자리가 매끄럽고 크기를 키워도 부드러워요.
  - **╱ 직선, ▭ 사각형, ◯ 원:** 드래그해서 크기를 정해요. **Shift** 를 누르면 반듯한 정사각형·정원·수평선이 돼요. **채우기** 를 켜면 속을 채워요.
- **굵기, 불투명도:** 붓과 도형 선의 굵기와 진하기
- **왼쪽 버튼:** 그리기, **오른쪽 버튼:** 지우기 (붓은 지우개, 도형은 그 모양대로 지워요)
- **↶ 되돌리기 (Ctrl+Z):** 방금 그린 것을 취소해요 (최대 30번).
- 가운데 십자선이 화면 정중앙이에요.
- **⊕ 가운데로:** 한쪽에 치우쳐 그렸어도 그림 전체를 정중앙으로 옮겨 줘요.
- **대칭 `+ 모양`:** 한쪽만 그리면 상하좌우가 자동으로 그려져요. (모든 도구에서 돼요)
- **'만들기' 조준선 가져오기:** 만든 조준선을 칸으로 옮겨서 고쳐 그릴 수 있어요.
- **🔁 이 그림을 발로란트 코드로 바꾸기:** 그림과 가장 비슷한 발로란트 조준선을 찾아서 코드를 복사해 줘요.
  발로란트 조준선 설정의 **가져오기(Import)**에 붙여넣으면 게임에도 적용돼요.
  - `+` 모양, 점, 테두리처럼 발로란트가 그릴 수 있는 모양은 **똑같이** 바뀌어요.
  - 원, 글자처럼 발로란트에 없는 모양은 비슷하게만 바뀌고, 일치율을 알려 줘요.
  - 검은색 칸은 테두리로 바뀌어요.

### 공통
- **지금 보고 있는 탭의 조준선**이 화면에 나와요.
- **크기** 슬라이더로 크기 조절, **F8** 로 켜기/끄기
- 발로란트 **설정 → 비디오 → 화면 모드 → `창 전체화면`** 으로 해야 게임 위에 보여요.
  (그냥 `전체화면` 모드면 게임이 오버레이를 가려요)

## 참고

- 게임 메모리를 건드리지 않고 화면 위에 그림만 그리는 방식이에요.
  그래도 외부 프로그램이니 사용은 본인 판단으로 해 주세요.
- 이동/사격 오차(조준선 벌어짐)는 반영되지 않고, 주 무기 조준선만 표시해요.
