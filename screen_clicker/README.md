# 🖱 화면 이미지 자동 클릭기

화면에 **박스(감시 영역)**를 정해두고, 그 박스 안에 **사진**(버튼 등)이나 **글자**(예: "확인")가 나타나면 **자동으로 클릭**해 주는 프로그램입니다.
항목은 **여러 개** 만들 수 있고, **클릭할 좌표**도 정할 수 있어요.

---

## 1. 실행하기 (Windows)

1. 파이썬 3.11 이상 또는 `uv`가 설치되어 있어야 합니다.
2. 이 폴더의 **`start.bat`을 더블클릭**합니다.
   (처음 한 번은 필요한 프로그램을 받느라 조금 걸려요)

> 직접 실행하려면: `pip install -r requirements.txt` 다음에 `python screen_clicker.py`

---

## 2. 사용법

| 순서 | 할 일 |
|---|---|
| ① 박스 | **➕ 새 항목** → **📐 화면에서 박스 그리기** → 감시할 곳을 드래그 (조금 넉넉하게) |
| ② 찾을 것 | **🖼 사진**: **✂ 화면에서 캡처**(버튼만 딱 맞게 드래그) 또는 **📂 사진 파일 올리기**<br>**🔤 글자**: 찾을 글자를 입력 (예: `확인`, `다음`, `OK`) |
| ③ 클릭할 곳 | **찾은 곳 가운데** / **찾은 곳에서 옆으로**(오른쪽·아래로 몇 픽셀) / **화면의 정해진 곳**(X, Y 좌표) |
| ④ 시작 | **💾 저장** → 메인 화면에서 **▶ 시작 (F9)** |

- 저장 전에 **🔍 지금 찾아보기(테스트)**로 잘 찾는지 확인할 수 있어요.
  찾은 곳은 **초록 상자**, 누를 곳은 **빨간 십자**로 보여주고, 글자 모드면 **읽은 글자**도 보여줘요.
- 박스나 찾을 것 중 **하나만 정해도 저장**돼요. 나머지는 나중에 **✏ 고치기**에서 채우면 돼요.

### 🔤 글자 찾기
- Windows에 들어있는 **글자 인식 기능**을 써요. 따로 설치할 건 없어요.
- **띄어쓰기·대소문자는 무시**해요. (`확 인` = `확인`, `ok` = `OK`)
- 글자를 한두 개 잘못 읽을 수도 있어서, **얼마나 똑같아야 클릭?**의 %로 비슷한 정도를 정해요.
  - 100% = 정확히 같을 때만 / 85% = 조금 달라도 OK
- 한국어 글자를 읽으려면 Windows에 **한국어**가 있어야 해요. (한국어 Windows는 기본으로 있어요.
  없으면 설정 > 시간 및 언어 > 언어에서 한국어 추가)

### 📍 클릭할 곳 (마우스 좌표)
| 고르기 | 설명 | 예시 |
|---|---|---|
| 찾은 곳 가운데 | 찾은 사진/글자의 한가운데를 클릭 | 기본 |
| 찾은 곳에서 옆으로 | 가운데에서 **오른쪽 ○픽셀, 아래 ○픽셀** 옮겨서 클릭 (왼쪽·위는 `-`) | "이름:" 글자를 찾고 오른쪽 입력칸 누르기 → 오른쪽 `150` |
| 화면의 정해진 곳 | 찾으면 **정해 둔 X, Y 좌표**를 클릭 | **📍 화면에서 찍기**로 누를 곳을 한 번 클릭하면 좌표가 들어가요 |

## 3. 저장 (1번, 2번, 3번 …)

- 저장하면 **박스 위치 + 찾을 것 + 클릭할 곳**이 한 묶음으로 프로그램에 저장돼요.
- 이름은 자동으로 **1번, 2번, 3번 …** 순서로 붙어요.
- **이름 바꾸기**: 목록에서 이름을 **두 번 클릭**하거나, **🏷 이름 바꾸기 (F2)** → 입력 후 **Enter** (취소는 Esc)
- **박스 위치 숫자로 고치기**: 고치기 창에서 X, Y, 폭, 높이를 직접 입력
- **저장된 것 가져오기**: 고치기 창 아래에서 다른 번호를 골라 **박스만 / 찾을 것만 / 클릭할 곳만 / 전부** 가져오기
- 목록에서 저장된 **사진을 작게**(글자는 🔤 글자로) 볼 수 있어요.
- 프로그램을 껐다 켜도 그대로 남아 있어요.

## 4. 설정 설명

| 설정 | 뜻 | 추천 |
|---|---|---|
| 얼마나 똑같아야 클릭? | 사진/글자가 몇 % 비슷하면 클릭할지 | 85% (잘못 누르면 올리고, 못 찾으면 내리기) |
| 클릭 방법 | 왼쪽 / 더블 / 오른쪽 클릭 | 왼쪽 클릭 |
| 한 번 클릭 후 쉬는 시간 | 같은 항목을 연달아 누르지 않게 기다리는 시간 | 2초 |
| 검사 간격 | 화면을 몇 초마다 볼지 | 0.5초 |
| 클릭 후 마우스 제자리로 | 클릭하고 마우스를 원래 위치로 돌려놓기 | 켜기 |

목록에서
- **사용** 칸 클릭 = 그 항목 켜기/끄기
- **이름** 두 번 클릭 = 이름 바꾸기 · **다른 칸** 두 번 클릭 = 고치기

---

## 5. 멈추는 방법

- **■ 멈춤** 버튼 또는 **F10**
- **비상 정지**: 마우스를 **화면 왼쪽 위 구석**으로 밀기

---

## 6. 잘 안 될 때

- **못 찾아요** → 이 프로그램 창이 박스를 가리고 있지 않은지 확인하세요. 정확도를 80%쯤으로 낮춰보세요.
- **글자를 못 읽어요** → 🔍 테스트에서 "읽은 글자"를 확인하세요. 박스를 글자 주변으로 좁히면 더 잘 읽어요.
- **엉뚱한 곳을 눌러요** → 정확도를 90% 이상으로 올리고, 박스를 좁게 그리세요.
- **사진을 다시 캡처** → 화면 배율(125% 등)이나 창 크기를 바꾸면 사진 크기가 달라져서 못 찾을 수 있어요. 그때는 다시 캡처하세요.
- 설정은 `settings.json`, 사진은 `images/` 폴더에 자동 저장됩니다.
