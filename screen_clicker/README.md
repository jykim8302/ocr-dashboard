# 🖱 화면 이미지 자동 클릭기

화면에 **박스(감시 영역)**를 정해두고, 그 박스 안에 **내가 올린 그림**(버튼 등)이 나타나면 **자동으로 클릭**해 주는 프로그램입니다.
항목은 **여러 개** 만들 수 있어요.

---

## 1. 실행하기 (Windows)

1. 파이썬 또는 `uv`가 설치되어 있어야 합니다.
2. 이 폴더의 **`start.bat`을 더블클릭**합니다.
   (처음 한 번은 필요한 프로그램을 받느라 조금 걸려요)

> 직접 실행하려면: `pip install -r requirements.txt` 다음에 `python screen_clicker.py`

---

## 2. 사용법 (3단계)

| 순서 | 할 일 |
|---|---|
| ① | **➕ 새 항목** → **📐 화면에서 박스 그리기** → 감시할 곳을 마우스로 드래그 (조금 넉넉하게) |
| ② | **✂ 화면에서 캡처** → 클릭할 버튼만 딱 맞게 드래그<br>또는 **📂 그림 파일 올리기**로 미리 캡처한 그림을 올리기 |
| ③ | **💾 저장** → 메인 화면에서 **▶ 시작 (F9)** |

- 저장 전에 **🔍 지금 찾아보기(테스트)**로 잘 찾는지 확인할 수 있어요.
- 박스나 사진 중 **하나만 정해도 저장**돼요. 나머지는 나중에 **✏ 고치기**에서 채우면 돼요.
- 박스 안에서 그림을 찾으면 **그림 가운데를 클릭**합니다.

---

## 3. 저장 (1번, 2번, 3번 …)

- 저장하면 **박스 위치 + 사진**이 한 묶음으로 프로그램에 저장돼요.
- 이름은 자동으로 **1번, 2번, 3번 …** 순서로 붙어요.
- **이름 바꾸기**: 목록에서 이름을 **두 번 클릭**하거나, **🏷 이름 바꾸기 (F2)** → 입력 후 **Enter** (취소는 Esc)
- **박스 위치 숫자로 고치기**: 고치기 창에서 X, Y, 폭, 높이를 직접 입력
- **저장된 것 가져오기**: 고치기 창 아래에서 다른 번호를 골라 **박스만 / 사진만 / 둘 다** 가져오기
- 목록에서 저장된 **사진을 작게** 볼 수 있어요.
- 프로그램을 껐다 켜도 그대로 남아 있어요.

---

## 4. 설정 설명

| 설정 | 뜻 | 추천 |
|---|---|---|
| 얼마나 똑같아야 클릭? | 그림이 몇 % 비슷하면 클릭할지 | 85% (잘못 누르면 올리고, 못 찾으면 내리기) |
| 클릭 방법 | 왼쪽 / 더블 / 오른쪽 클릭 | 왼쪽 클릭 |
| 한 번 클릭 후 쉬는 시간 | 같은 항목을 연달아 누르지 않게 기다리는 시간 | 2초 |
| 검사 간격 | 화면을 몇 초마다 볼지 | 0.5초 |
| 클릭 후 마우스 제자리로 | 클릭하고 마우스를 원래 위치로 돌려놓기 | 켜기 |

목록에서
- **사용** 칸 클릭 = 그 항목 켜기/끄기
- **이름** 두 번 클릭 = 이름 바꾸기 · **다른 칸** 두 번 클릭 = 고치기

---

## 5. 멈추는 방법

- **■ 멈춤** 버튼 또는 **F10**
- **비상 정지**: 마우스를 **화면 왼쪽 위 구석**으로 밀기

---

## 6. 잘 안 될 때

- **못 찾아요** → 이 프로그램 창이 박스를 가리고 있지 않은지 확인하세요. 정확도를 80%쯤으로 낮춰보세요.
- **엉뚱한 곳을 눌러요** → 정확도를 90% 이상으로 올리고, 박스를 좁게 그리세요.
- **그림을 다시 캡처** → 화면 배율(125% 등)이나 창 크기를 바꾸면 그림 크기가 달라져서 못 찾을 수 있어요. 그때는 다시 캡처하세요.
- 설정은 `settings.json`, 그림은 `images/` 폴더에 자동 저장됩니다.
