# 스프레이 반동 분석기 (발로란트)

발로란트 총의 반동 패턴을 보고, 내 사격을 분석하고, 보정 연습까지 하는 웹 도구예요.
설치할 것 없이 `index.html`을 브라우저로 열면 바로 돼요.

## 기능 3가지

| 탭 | 하는 일 |
| --- | --- |
| 총기별 패턴 | 밴달·팬텀·스펙터·불독·스팅어·아레스·오딘의 반동이 어느 방향으로 튀는지 그림으로 보여줘요. 마우스를 어떻게 움직여야 하는지(보정 길)도 같이 보여줘요. |
| 내 스프레이 분석 | 사격장에서 벽에 쏜 스크린샷을 올리면 탄 자국을 찾아서 점수와 코칭("더 아래로 당기세요" 등)을 알려줘요. |
| 보정 연습 | 과녁을 누르고 있으면 연사돼요. 누른 채로 마우스를 아래로 끌어 반동을 잡고, 점수를 받아요. |

## 내 스프레이 분석 쓰는 법

1. 사격장에서 벽에 대고 연사해요.
2. 스크린샷을 올려요. (끌어다 놓기, Ctrl+V 붙여넣기도 돼요)
3. 처음 조준했던 곳을 클릭해요.
4. 탄 자국을 쏜 순서대로 클릭하거나 **탄 자국 자동 찾기**를 눌러요.
   - 잘못 찍힌 점은 다시 클릭하면 지워져요.
   - 너무 적게 찾으면 **민감도**를 올려요.

거리는 화면 높이를 100으로 본 비율(%)이라 해상도가 달라도 같은 기준으로 비교돼요.

## 알아둘 점

- 총기별 패턴은 게임 속 반동 경향을 단순하게 옮긴 **근사 모형**이에요. 실제와 조금 다를 수 있어요.
- 자동 찾기는 탄 자국이 겹치면 하나로 셀 수 있어요. 그럴 땐 직접 클릭해서 더해주세요.
- Riot Games와 관련 없는 팬 도구예요.
