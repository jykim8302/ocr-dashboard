================================================
   나만의 AI 비서 - 사용법
================================================

★★ 가장 중요 ★★
반드시 "압축을 먼저 푼 뒤"에 실행하세요.
zip 파일을 더블클릭해서 열린 창 안에서 바로 실행하면
"파일을 찾을 수 없습니다" 오류가 납니다.

  1) 나만의AI.zip 에 우클릭 > "압축 풀기" (또는 "여기에 압축 풀기")
  2) 풀린 폴더를 엽니다. 안에 my_ai 폴더가 보이면 제대로 푼 것입니다.
  3) 그 폴더 안의 실행 파일을 더블클릭합니다.


[1] 실행하기
    - 윈도우  : AI실행.bat  더블클릭
    - 맥      : AI실행.command  더블클릭
                (처음 한 번은 파일 우클릭 > 열기 를 선택하세요)

    검은 창이 뜨고, 처음 한 번은 필요한 프로그램을 설치합니다.
    2~5분 걸릴 수 있으니 그대로 기다려 주세요.
    설치가 끝나면 브라우저가 자동으로 열립니다.

    * 검은 창은 끄지 마세요. 닫으면 AI도 꺼집니다.
    * 브라우저가 안 열리면 검은 창에 표시된
      Local URL (보통 http://localhost:8501) 을 주소창에 넣으세요.

[2] API 키 입력
    화면 왼쪽 위 칸에 키를 한 번만 붙여넣으면 됩니다.
    키 발급: https://console.anthropic.com

[3] 설정 바꾸기
    왼쪽 사이드바 1~8번을 열어서 원하는 대로 바꾸고
    맨 아래 "설정 저장"을 누르세요.

    1. 성격 / 역할        5. 두뇌 (모델)
    2. 말하기 방식        6. 도구 (인터넷 검색)
    3. 규칙 / 제한        7. 고급
    4. 나에 대한 정보     8. 화면

[4] 캐릭터 바꾸기
    사이드바 맨 위 "프리셋"에서 골라서 불러오기.
    기본 비서 / 영어 선생님 / 코딩 도우미 / 요리사


------------------------------------------------
   문제가 생겼을 때
------------------------------------------------

* "AI 프로그램 파일을 찾을 수 없습니다" 라고 나오면
  -> 압축을 풀지 않고 실행한 것입니다.
     맨 위 ★★ 가장 중요 ★★ 부분을 다시 보세요.

* 검은 창에 "Email:" 이라고 뜨면서 멈춰 있다면
  -> 그냥 엔터를 한 번 누르세요. 바로 넘어갑니다.
     (이 버전에서는 더 이상 묻지 않습니다)

* "파이썬이 설치되어 있지 않습니다" 라고 나오면
  -> https://www.python.org/downloads/ 에서 설치하세요.
     윈도우는 설치 화면에서 "Add python.exe to PATH" 를 꼭 체크!

* 맥에서 더블클릭이 안 되면
  -> 파일에서 우클릭 > 열기 를 선택하세요.
     그래도 안 되면 터미널에서 아래 한 줄을 실행하세요.
     chmod +x "AI실행.command"

* 설치가 실패하면
  -> 인터넷 연결을 확인하고 다시 더블클릭해 보세요.

자세한 설명은 my_ai/README.md 파일에 있습니다.
