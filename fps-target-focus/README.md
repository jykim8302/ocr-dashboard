# 1인칭 컨트롤러 + 타겟 포커스

`FPS_타겟포커스.html` 파일을 **더블클릭**하면 브라우저에서 바로 실행됩니다.
설치·서버·라이브러리 전부 필요 없는 단일 HTML 파일입니다.

## 조작
| 키 | 동작 |
|---|---|
| `W A S D` | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 |
| 마우스 | 시점 회전 (화면 클릭 시 마우스 고정) |
| `Esc` | 마우스 고정 해제 (왼쪽 설정 조작용) |
| `Tab` | 타겟 포커스 ON / OFF |
| `H` | UI 숨기기 |

## 타겟 포커스 동작
지정한 물체(TARGET A~F)가 아래 **두 조건을 동시에** 만족하면 시점이 부드럽게
회전해 그 물체를 화면 정중앙에 맞춥니다.

1. **거리 조건** — 플레이어와의 거리가 `감지 거리`(기본 18m) 이내
2. **화면 영역 조건** — 화면에 투영된 위치가 화면 중앙 원(기본 화면 높이의 18%) 안쪽

두 조건이 모두 참인 대상 중 화면 중심에 가장 가깝고 가까운 것이 선택되며,
잠긴 뒤에는 살짝 벗어나도 유지되도록 히스테리시스(거리 1.25배 / 영역 1.6배)가 적용됩니다.

## 설정 (왼쪽 패널)
감지 거리 · 화면 영역 반경 · 회전 속도 · 마우스 감도 · 시야각(FOV)을 실시간으로 조절할 수 있습니다.

## 구현
외부 라이브러리 없이 Canvas 2D 위에 직접 3D를 그립니다.
- 월드 → 뷰 변환(yaw/pitch), 원근 투영, 근평면 클리핑(Sutherland–Hodgman)
- 면 단위 깊이 정렬(화가 알고리즘) + 후면 제거 + 방향광 셰이딩
- 포인터 락 기반 마우스 룩, AABB 충돌, 중력/점프
