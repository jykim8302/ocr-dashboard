# E 연타 매크로

**F12** 로 켜고, **좌클릭을 누르고 있는 동안 E 를 연타**합니다.

## 사용법
1. [AutoHotkey v2](https://www.autohotkey.com/) 설치
2. `e_spam.ahk` 더블클릭 → 실행
3. **F12** 누르기 → 켜짐 (화면 표시 없음)
4. 좌클릭을 꾹 누르면 E 연타, 떼면 멈춤
5. 다시 **F12** → OFF / **Ctrl+F12** → 종료

## 팁
- 게임이 E 를 잘 못 받으면 파일 위쪽의 `간격 := 1` 을 `10` 정도로 올리세요.
- 게임이 관리자 권한으로 실행 중이면 스크립트도 **우클릭 → 관리자 권한으로 실행** 해야 합니다.
