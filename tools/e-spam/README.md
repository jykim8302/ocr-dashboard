# E 연타 매크로

**F12** 로 켜고, **좌클릭을 누르고 있는 동안 E 를 연타**합니다.
작은 상태 창에 **ON(초록) / OFF(회색)** 가 표시됩니다.

## 사용법
1. `e_spam.exe` 더블클릭 → 화면 왼쪽 위에 상태 창이 뜹니다
2. **F12** (또는 창의 버튼) → ON
3. 좌클릭을 꾹 누르면 E 연타, 떼면 멈춤
4. 다시 **F12** → OFF / **Ctrl+F12** 또는 창 X → 종료

## 팁
- **렉이 걸리거나 E 가 씹히면** 상태 창의 슬라이더를 왼쪽(느리게)으로 옮기세요. 설정은 자동 저장됩니다.
- 게임이 관리자 권한으로 실행 중이면 exe 도 **우클릭 → 관리자 권한으로 실행** 하세요.
- 백신이 exe 를 오진할 수 있습니다 (AutoHotkey 로 만든 exe 에 흔한 일).
