# 픽셀 클릭기

화면 **정가운데 1픽셀** 색이 바뀌면 그 자리를 **딱 한 번 클릭**하는 프로그램이에요.

## 실행 방법 (Windows)

1. [Python](https://www.python.org/downloads/) 설치 (설치 시 **"Add Python to PATH"** 체크)
2. 파일을 모두 한 폴더에 넣고 `run_windows.bat` 더블클릭 → 작은 창이 떠요

(다른 OS: `pip install -r requirements.txt` 후 `python pixel_clicker.py`)

## 사용 순서

1. 원하는 화면에서 **단축키**(기본 F8) 또는 **[감시 켜기 / 끄기]** 버튼
   → 지금 가운데 색을 기억하고 감시 시작 (● 감시 중)
2. 감시가 꺼지는 경우 (○ 꺼짐)
   - 색이 바뀌면 → **딱 한 번 클릭** → 감시 꺼짐
   - 감시 중에 단축키를 또 누르면 → 클릭 없이 감시 꺼짐
3. 꺼진 상태에서 단축키 → 그 순간 화면으로 다시 감시 시작

프로그램을 끄려면 창을 닫으면 돼요.

## 창에서 바꿀 수 있는 것

| 항목 | 설명 |
|---|---|
| **[단축키 설정]** | 버튼을 누르고 원하는 키를 누르면 끝 (예: F8, Ctrl+Alt+S) |
| **색 차이 허용치** | 이만큼 이상 색이 달라야 "바뀜"으로 인정 (0~255, 기본 10) |
| **클릭 버튼** | 왼쪽 / 오른쪽 클릭 |

바꾼 설정과 창 위치는 `hotkey_settings.json`에 **자동 저장**돼서, 다음에 켜도 그대로예요.

## 참고

- 창은 항상 위에 떠 있어요. 화면 가운데를 가리지 않게 두세요.
- 마우스가 화면 **왼쪽 위 모서리**에 있으면 안전을 위해 클릭하지 않아요.
