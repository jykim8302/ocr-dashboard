# 픽셀 클릭기

화면 **정가운데 1픽셀** 색이 바뀌면 그 자리를 **딱 한 번 클릭**하는 프로그램이에요.

## 실행 방법 (Windows)

1. [Python](https://www.python.org/downloads/) 설치 (설치 시 **"Add Python to PATH"** 체크)
2. 파일을 모두 한 폴더에 넣고 `run_windows.bat` 더블클릭 → 작은 창이 떠요

(다른 OS: `pip install -r requirements.txt` 후 `python pixel_clicker.py`)

## 단축키 방식 (창에서 선택)

**누르고 있는 동안** (기본)
- 단축키(기본 F8)를 **누르고 있는 동안만** 감시해요
- 누른 채로 색이 바뀌면 → **딱 한 번 클릭** → 감시 꺼짐
- 키를 떼면 감시 꺼짐 → 다시 누르면 그 순간 화면으로 다시 감시

**누를 때마다 켜기/끄기**
- 한 번 누르면 감시 켜짐, 또 누르면 꺼짐
- 색이 바뀌면 → **딱 한 번 클릭** → 감시 꺼짐

## 창에서 바꿀 수 있는 것

| 항목 | 설명 |
|---|---|
| **[단축키 설정]** | 버튼을 누르고 원하는 키를 누르면 끝 (예: F8, Ctrl+Alt+S) |
| **단축키 방식** | 누르고 있는 동안 / 누를 때마다 켜기·끄기 |
| **색 차이 허용치** | 이만큼 이상 색이 달라야 "바뀜"으로 인정 (0~255, 기본 10) |
| **클릭 버튼** | 왼쪽 / 오른쪽 클릭 |

바꾼 설정과 창 위치는 `hotkey_settings.json`에 **자동 저장**돼서, 다음에 켜도 그대로예요.

## 클릭이 인식 안 될 때

1. 창에 **[관리자로 다시 실행]** 버튼이 보이면 눌러 주세요.
   게임처럼 관리자 권한으로 도는 프로그램에는 일반 프로그램의 클릭·키 입력이 전달되지 않아요.
2. 게임이면 **창 모드** 또는 **전체 창 모드(테두리 없음)** 로 바꿔 주세요.
   "전체 화면" 모드에서는 화면 색을 못 읽는 경우가 있어요.
3. "누르고 있는 동안" 방식에서 단축키에 **Ctrl/Alt/Shift가 들어 있으면**,
   클릭이 Ctrl+클릭처럼 들어가요. **F8 같은 키 하나**를 쓰는 게 좋아요.

## 참고

- 창은 항상 위에 떠 있어요. 화면 가운데를 가리지 않게 두세요.
- 마우스가 화면 **왼쪽 위 모서리**에 있으면 안전을 위해 클릭하지 않아요.
