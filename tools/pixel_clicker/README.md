# 픽셀 변화 자동 클릭기

**단축키를 누르면**, 그 순간 화면 **정가운데 1픽셀** 색을 기억해요.
그 색이 바뀌면 그 자리를 **딱 한 번 클릭**하고 감시를 꺼요.

## 실행 방법 (Windows)

1. [Python](https://www.python.org/downloads/) 설치 (설치 시 **"Add Python to PATH"** 체크)
2. 파일을 모두 한 폴더에 넣고 `run_windows.bat` 더블클릭
3. **처음 한 번만** 단축키를 정해요 → 원하는 키를 그냥 누르면 돼요
   - 감시 시작 키 (예: F8, Ctrl+Alt+S)
   - 프로그램 종료 키 (예: F12)

(다른 OS: `pip install -r requirements.txt` 후 `python pixel_clicker.py`)

## 사용 순서

1. 프로그램을 켜 두면 **대기** 상태예요
2. 원하는 화면에서 **시작 키** → 지금 가운데 색을 기억하고 감시 시작
3. 색이 바뀌면 → **딱 한 번 클릭** → 감시 꺼짐 (프로그램은 켜진 채 대기)
4. 다시 **시작 키** → 그 순간 화면으로 다시 감시 시작

프로그램을 끄려면 **종료 키**를 누르거나, 마우스를 화면 **왼쪽 위 모서리**로 옮기세요.

## 단축키 바꾸기

`단축키_바꾸기.bat` 더블클릭 → 새 키를 누르면 끝.
정한 키는 `hotkey_settings.json`에 저장돼서 다음에도 그대로 써요.

## 옵션 (필요할 때만)

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--tolerance 30` | 이만큼 이상 색이 달라야 "바뀜"으로 인정 (0~255) | 10 |
| `--button right` | 오른쪽 클릭 | left |

`run_windows.bat`를 메모장으로 열어서 `python pixel_clicker.py` 뒤에 적으면 돼요.
