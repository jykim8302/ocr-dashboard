# 마우스 움직임 따라하기 (Mouse Tracer)

마우스가 움직인 길을 **그대로** 기록했다가, 똑같은 속도로 **실제로 움직이며** 다시 재생하는 프로그램입니다.
좌표로 순간이동시키지 않고, 기록된 시간 간격대로 한 칸씩 밀어주기 때문에 사람이 직접 움직이는 것과 같은 궤적이 나옵니다.

## 실행 방법

`MouseTracer.bat` 을 **더블클릭**하면 끝입니다.
처음 실행하면 같은 폴더에 `mouse_tracer.py` 가 자동으로 만들어지고 창이 뜹니다.

- Windows 전용입니다.
- Python 3 가 필요합니다. 없으면 자동 설치를 물어봅니다.
- 별도의 라이브러리 설치는 필요 없습니다. 파이썬 기본 기능만 씁니다.

## 단축키

| 키 | 기능 |
|----|------|
| F9 | 녹화 시작 / 중지 |
| F10 | 재생 시작 / 중지 |
| F11 | 전부 정지 |

창이 뒤에 있어도 단축키는 그대로 동작합니다.

## 설정

- **반복 횟수** : 0 을 넣으면 정지할 때까지 무한 반복합니다.
- **재생 속도** : 1.0 이 녹화한 그대로입니다. 2.0 이면 두 배 빠르게 재생합니다.
- **키보드 입력도 함께 기록** : 마우스뿐 아니라 키보드도 같이 따라 합니다.
- **재생 전 시작 위치로 커서 이동** : 녹화를 시작했던 지점부터 다시 그립니다.
- **정밀 모드** : 재생하는 동안만 마우스 가속을 꺼서 궤적을 정확히 재현합니다. 재생이 끝나거나 프로그램을 닫으면 원래 설정으로 자동 복구됩니다.

기록은 `파일로 저장` 으로 저장해 두었다가 `파일 불러오기` 로 다시 쓸 수 있습니다.

## 어떻게 동작하나요

- 녹화는 Win32 **Raw Input**(`WM_INPUT`) 을 씁니다. 마우스 장치가 보고하는 원시 이동량(dx, dy)을 폴링 주기 그대로 받아 적습니다. 화면 좌표를 훑는 방식이 아니라서 미세한 떨림까지 남습니다.
- 재생은 `SendInput` 의 **상대 이동**(`MOUSEEVENTF_MOVE`) 으로 합니다. 기록된 시각마다 같은 크기의 이동을 넣어주므로 커서가 실제로 그 경로를 따라 흘러갑니다.
- 재생 중 만들어진 입력에는 표식을 달아두어, 녹화 중이더라도 자기 입력을 다시 기록하지 않습니다.
- 재생을 중간에 멈추면 아직 눌린 채인 버튼과 키를 자동으로 놓아줍니다.

## 주의

- 게임의 안티치트나 보안 프로그램은 합성 입력을 차단하거나 제재할 수 있습니다. 허용된 곳에서만 쓰세요.
- 무한 반복 재생 중에는 F11 로 언제든 멈출 수 있습니다.
