# 화면 번역기

단축키 한 번으로 **지금 보고 있는 창의 영어를 한국어로 번역**해 주는 Windows 프로그램입니다.

| 단축키 | 하는 일 |
|---|---|
| `Ctrl + Shift + T` | 지금 보고 있는 창 전체 번역 |
| `Ctrl + Shift + R` | 마우스로 드래그한 부분만 번역 |
| `Esc` | 번역 창 닫기 |

## 사용법

1. **파이썬 설치** (처음 한 번) — https://www.python.org/downloads/
   설치 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 이 폴더의 **`실행.bat`** 을 더블클릭
   - 처음에는 필요한 것을 자동으로 설치해요 (1~3분).
   - 다음부터는 바로 켜집니다.
3. "준비 완료!" 가 뜨면, 영어가 있는 창을 클릭하고 `Ctrl + Shift + T`

번역 창이 원래 창 옆에 뜨고, 번역문 아래에 회색으로 원문이 같이 나와요.
**번역 복사** 버튼으로 번역문을 복사할 수 있어요.

> 팁: 번역 창이 떠 있는 상태에서 원래 창을 스크롤하고 다시 단축키를 누르면 새 내용으로 바뀝니다.

## 어떻게 동작하나요?

```
단축키 → 창 화면 찍기 → 글자 읽기(OCR, 내 컴퓨터에서) → 문단으로 묶기 → 구글 번역 → 번역 창
```

- 글자 읽기는 인터넷 없이 내 컴퓨터에서 합니다 (RapidOCR).
- 번역은 구글 번역을 쓰므로 **인터넷이 필요**해요. 읽은 글자가 구글로 전송되니, 비밀 문서에는 쓰지 마세요.

## 설정 바꾸기

`screen_translator.py` 맨 위를 메모장으로 열어 바꾸면 됩니다.

```python
HOTKEY_WINDOW = "ctrl+shift+t"   # 현재 창 번역
HOTKEY_AREA = "ctrl+shift+r"     # 영역 선택 번역
TARGET_LANG = "ko"               # 번역할 언어
FONT_SIZE = 13                   # 번역 글자 크기
```

## 문제가 생기면

- **"단축키를 쓸 수 없어요"** → 이미 켜져 있거나, 다른 프로그램이 같은 키를 써요. 위 설정에서 키를 바꿔 보세요 (예: `"ctrl+alt+t"`, `"f9"`).
- **설치가 꼬였을 때** → 이 폴더의 `.venv` 폴더를 지우고 `실행.bat` 을 다시 실행하세요.
- 그 외 오류는 이 폴더의 `오류기록.txt` 에 남습니다.
